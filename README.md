# 🚀 SkillPilot AI

An AI-powered learning platform that helps users learn **anything** through personalized roadmaps, AI tutoring, quizzes, projects, and interview preparation.

## ✨ Features

- 🔍 AI-powered skill search
- 📚 Personalized learning roadmap
- 🤖 AI Tutor
- 📝 Quiz Generator
- 📈 Progress Tracking
- 💻 Coding Playground
- 🎯 Interview Preparation
- 📄 Resume Builder

## 🛠 Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS
- React Router
- Axios
- Redux Toolkit (planned)

### Backend
- FastAPI
- Python
- PostgreSQL
- SQLAlchemy

### AI
- OpenAI / Claude API
- RAG (planned)
- MCP (planned)
- AI Agents (planned)
